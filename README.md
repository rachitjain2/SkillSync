> **SkillSync AI** is a functional, next-generation AI talent matching platform that replaces traditional resume guesswork and black-box job boards with **verifiable skill extraction, mathematical vector matching, and explainable match diagnostics**.

---

## 🌟 Executive Summary & Core Philosophy

Traditional hiring platforms present job listings like generic classified ads with zero insight into candidate readiness or missing qualifications. **SkillSync AI** operates as an **Explainable Career Operating System**:

1. **Instant Ingestion & OCR Tokenization**: Extracts entities, skills, projects, and work history from candidate resumes in real time.
2. **Deterministic Match Scoring & Vector Breakdown**: Computes explainable fit percentages across Technical Skills, Relevant Projects, Education, Experience, and Domain Synergy.
3. **Transparent Skill Gap Diagnostics**: Identifies exactly what skills are missing (e.g. AWS, Docker, JAX) and why.
4. **Actionable Sprints to 100% Fit**: Automatically compiles personalized learning roadmaps to bridge qualified skill gaps.
5. **Interactive AI Career Copilot**: Provides 1-on-1 interview simulations, prompt debugging, and tailored application strategies.

### 2. 📄 3-Step Resume Intelligence Lab
- **Step 1: Upload Resume**: Drag-and-drop support for PDF, DOCX, and TXT files with an animated telemetry progress bar and 1-click sample candidate loading (*Rachit Jain, Alex Rivera, Sarah Lin*).
- **Step 2: Live AI Processing**: Animated radar scanline beam and sequential terminal stages:
  1. *Reading resume* $\rightarrow$ Layout structure & tokenization
  2. *Extracting information* $\rightarrow$ Personal info & verified education
  3. *Identifying skills* $\rightarrow$ Taxonomy parsing & categorization
  4. *Analyzing experience* $\rightarrow$ Quantified metrics & repo highlights
  5. *Building talent profile* $\rightarrow$ Vector synthesis & summary generation
- **Step 3: AI-Generated Talent Dossier**:
  - Executive AI Summary & Personal Contact Information
  - **Skill Confidence & Evidence from Resume**: Displays confidence scores backed by explicit resume citations (e.g. *Python: 96% — Used in 4 projects & 2 internships*).

## 💻 Getting Started & Local Development

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/skillsync-ai.git
   cd skillsync-ai
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables** (Optional for Supabase integration):
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
   *(Note: The application includes full mock failover so all features work seamlessly out of the box without external API keys!)*

4. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

5. **Build for Production**:
   ```bash
   npm run build
   ```
